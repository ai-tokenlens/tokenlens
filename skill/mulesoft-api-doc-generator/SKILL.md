# MuleSoft API Documentation Generator

Generate structured Markdown docs from a MuleSoft RAML/OAS spec

## Usage

Place a RAML (.raml) or OpenAPI (.yaml/.json) spec file in your working directory,
then invoke this skill. It produces a structured Markdown document covering:
endpoints, request/response schemas, authentication, error codes, and examples.
